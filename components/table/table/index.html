GitHub

A native <table> on Bootstrap 6 .table with the density of Taiga UI's table. ngsTable adds striped, hover, bordered and size options, ngsTh adds sortable headers with aria-sort, and a few small pieces add row selection, empty and loading states and a scroll region with a sticky header. You render the rows with @for, so the table stays fast: it handles 1,000 rows without virtual scrolling, and a CDK viewport covers much longer ones.

Basic

Put ngsTable on a <table> and use ordinary rows and cells. The directive only adds Bootstrap classes, so every native semantic stays. Name the table with a <caption>.

Rich cells

Cells hold anything: two-line text, chips, Bootstrap .avatars, a status dot, a .progress bar and icon buttons. The table supplies the size, the row separators, the header and the selection column; the rest is ordinary markup.

Sorting

Give a header a key, ngsTh="age", to make it sortable. The sort is one model, [(sort)], holding { key, direction } or null. Clicking cycles ascending, descending, none. The table does not reorder your rows: sort them with ngsSortRows, which takes an optional comparator per column (here, priority sorts by importance). For a server, send the sort to the API instead.

Row selection

[(selected)] holds the selected rows. Mark each row with [ngsRow]="row", add a ngsRowSelect cell for its checkbox and a [ngsSelectAll]="rows" header cell. Selected rows get aria-selected="true" and .table-active.

Scroll and sticky header

Wrap the table in ngs-table-container to scroll it in both directions. Give it a label: once the table overflows, the region is focusable, so the keyboard can scroll it. maxHeight with sticky keeps the header in view.

Empty and loading

[loading] marks the table aria-busy and shows a spinner over the container. A tr ngsTableEmpty row spans the columns when there is nothing to show; its content is yours, or the translated default.

Virtual scrolling

For very long tables, put the table in a CDK cdk-virtual-scroll-viewport and add ngsTableViewport. Only the rows in view are rendered, here out of 10,000. Rows need one fixed height (itemSize: 44 for md, 34 for sm, 57 for lg, with one line of text). Set aria-rowindex on each row and rowCount on the table.

Accessibility

The table is native, so screen readers announce rows, columns and header cells without ARIA. A sortable header sets aria-sort on the th and holds a real <button> named by the column text plus hidden text with the current sort ("Name, sorted ascending"); the strings come from NgsI18n.table. Keep a <caption> (visually hidden if needed) as the table's name.

A scrolling container is a role="region" named by label and takes tabindex="0" only while it overflows, which satisfies axe's scrollable-region-focusable. Selection checkboxes are ngs-checkbox with a hidden name ("Select row", or your label), and rows carry aria-selected. When the DOM holds only a page of the data, set rowCount to the full count for aria-rowcount. A loading table is aria-busy and its spinner is a status region.
