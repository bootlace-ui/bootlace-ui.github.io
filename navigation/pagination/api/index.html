<ngs-pagination>Component

NgsPagination

Page navigation built on Bootstrap 6 .pagination . The model is [(page)] (1-based) with length , the total number of pages. A list that knows a total item count (a table) divides it by its page size itself, so this control stays a plain "page n of N" and knows nothing of rows. 

<ngs-pagination [(page)]="page" [length]="24" />
<ngs-pagination [(page)]="page" [length]="24" [siblings]="2" edges size="sm" />

NgsPaginationItemType

One entry of the page window: a page number, or a gap standing for hidden pages. 

type NgsPaginationItem = number | 'ellipsis-start' | 'ellipsis-end'

ngsPaginationItemsFunction

Computes the page window: the first and last boundary pages, siblings pages either side of page , and an ellipsis for each gap. The number of items stays constant while paging, so the control does not change width, and an ellipsis never hides a single page (it shows it instead). 

ngsPaginationItems(page: number, length: number, siblings?: number, boundary?: number): Array<NgsPaginationItem>
